# 📚 Website Peminjaman Buku Perpustakaan

Sistem informasi perpustakaan berbasis website yang digunakan untuk mengelola peminjaman dan pengembalian buku secara digital.  
Project ini dibuat untuk mempermudah proses manajemen buku, data pengguna, serta transaksi peminjaman di perpustakaan.

---

## ✨ Fitur Utama

- 🔐 Login & autentikasi pengguna
- 📖 Melihat daftar buku
- ➕ Menambahkan data buku
- ✏️ Edit dan hapus data buku
- 📚 Peminjaman buku
- 📥 Pengembalian buku
- 👤 Manajemen data user
- 📊 Dashboard informasi perpustakaan
- 🔍 Pencarian buku

## 🚀 Cara Menjalankan Project

### 1. Clone Repository

```bash
git clone https://github.com/radityaputraa-sketch/Website-Peminjaman-Buku-Perpus.git
```

### 2. Masuk ke Folder Project

```bash
cd Website-Peminjaman-Buku-Perpus
```

### 3. Jalankan Local Server

Jika menggunakan XAMPP:

- Pindahkan folder project ke:
```bash
htdocs/
```

- Aktifkan:
  - Apache
  - MySQL

### 4. Import Database

- Buka phpMyAdmin
- Buat database baru
- Import file `.sql` yang tersedia pada folder database

### 5. Jalankan di Browser

```bash
http://localhost/Website-Peminjaman-Buku-Perpus
```
